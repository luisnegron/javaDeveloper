# javaDeveloper 🚀

Repositorio de aprendizaje y práctica de **Java Backend Development**, dentro de mi plan de formación intensiva para incorporarme al sector IT en España.

## 📋 Descripción

Proyecto inicial del bootcamp personalizado. Consiste en una aplicación Java que se compila y ejecuta **directamente desde la terminal**, sin depender de ningún IDE, para afianzar los fundamentos del flujo de trabajo de un desarrollador:

```
código fuente (.java)  →  compilador (javac)  →  bytecode (.class)  →  JVM (java)
```

## 🛠️ Requisitos

- **JDK 17** o superior ([Eclipse Temurin](https://adoptium.net/))
- **Git**
- Terminal (bash)

## ▶️ Ejecución

```bash
# 1. Compilar
javac HolaMundo.java

# 2. Ejecutar
java HolaMundo
```
